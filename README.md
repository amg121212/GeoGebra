# Hesapla

iPad için kişisel hesap makinesi uygulaması (ana ekrana eklenebilen web uygulaması).
Hesaplama ve çizim motoru olarak GeoGebra'nın resmi gömülebilir motoru kullanılır.

## Özellikler
- Açılış ekranı: Grafik, Geometri, 3B, CAS, Olasılık, Bilimsel
- Yan menü: Tümünü Temizle, Aç, Kaydet, Resim Olarak Dışa Aktar, Paylaş, Hesap Makinesini Değiştir, Ayarlar, Yardım
- Komutlar paneli: türev, integral, kök, ekstremum, dönüm noktası, teğet, limit, denklem çözme, çarpanlara ayırma…
- Otomatik kayıt, cihazda dosya kaydetme/açma, Türkçe/İngilizce, açık/koyu tema

## iPad'e kurulum
1. Bu klasörü GitHub Pages ile yayınla (Settings → Pages → Branch seç → Save).
2. iPad'de Safari ile yayın adresini aç.
3. Paylaş → **Ana Ekrana Ekle**.

İlk açılışta internet gerekir. Her hesap makinesini bir kez internetle açtıktan sonra önbellekten çalışır.
